# Prompt Sidecar 原型 · 第三轮

日期：2026-11-18。仅静态原型图片，未修改运行中的前端。

## 本轮确认的产品要求

- 主界面严格分为左右两栏，不增加侧栏；品牌栏只保留产品名和设置入口等。
- 左栏：快速选择会话、原始草稿、参考会话内容开关、四种常驻模式、输出规则、润色与分析下一步入口。
- 右栏：当前进展、建议下一步、条件出现的需决定事项、可编辑提示词和复制/发送操作。
- 当前进展说明已完成和尚未完成事项，仅一两句话。
- 下一步建议必须同时说明具体行动和原因。
- 只有阻塞、信息不足或冲突时才展示需要用户决定的事项；正常状态不占位。
- 主区域不展示上下文消息条数/字符数量，不重复会话身份或连接状态；原始详情仍可通过详情入口查看。
- 右侧提示词可以修改、复制并显式发送到选中的会话；不自动发送。
